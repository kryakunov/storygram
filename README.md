# Сторис анонимно

PHP-сервис для просмотра **публичных** сторис с **открытых** профилей без входа в Instagram. Работает на обычном shared-хостинге: PHP 7.4+, Apache (или nginx), FTP. Node, npm, Docker и Composer не нужны.

Сейчас подключён только mock-источник. Реальные ники Instagram не ищутся — для проверки используйте `luna.travels`.

## Загрузка на shared-хостинг

1. В панели хостинга включите **PHP 8.0+** (подойдёт и 7.4).
2. Залейте все файлы проекта в `public_html` (или в папку домена) по FTP.
3. Права на папку `data` и `data/cache`: **775** или **777**, чтобы PHP мог писать кэш и историю поиска.
4. Откройте `config.php` и задайте:
   - `ip_hash_salt` — случайная строка
   - `admin_token` — секрет для `/admin`
   - `app_url` — `https://ваш-домен.ru` (можно оставить пустым, тогда URL возьмётся автоматически)
   - `yandex_verification` — код из Яндекс.Вебмастера
5. Откройте сайт. Поиск: `luna.travels`.

Если сайт лежит не в корне, а в подпапке (`public_html/stories/`), заливайте туда весь проект — пути считаются сами.

Нужен `mod_rewrite`. Если ЧПУ не работают, проверьте, что `.htaccess` не игнорируется (`AllowOverride All`). Запасной вариант без rewrite: `https://домен.ru/index.php?r=/search&u=luna.travels`.

## Локально

```bash
php -S 127.0.0.1:8080
```

Откройте http://127.0.0.1:8080

## Демо-аккаунты

| Ник | Результат |
| --- | --- |
| `luna.travels` | Открытый, фото + видео |
| `cafe.neon` | Открытый, только фото |
| `city.lights` | Открытый, больше видео |
| `quiet.garden` | Открытый, нет активных сторис |
| `private.mode` | Закрытый — отказ |
| `down.stream` | Сбой источника |
| любой другой | Профиль не найден |

## Что внутри

- Страницы: `/`, `/search`, `/recent`, `/admin`, `/pricing`
- SEO: title/H1 под кластер «смотреть сторис Инстаграм анонимно», FAQ JSON-LD, `sitemap.xml`, `robots.txt`
- Кэш и история поиска — JSON-файлы в `data/`
- Язык по умолчанию русский, переключатель RU/EN

Закрытые аккаунты и обход Instagram не поддерживаются.
